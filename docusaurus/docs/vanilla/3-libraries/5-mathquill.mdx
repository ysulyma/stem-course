# MathQuill

To allow viewers to enter custom formulas, you can use [MathQuill](http://mathquill.com/).

## Basic setup

We will load MathQuill from a CDN: https://cdnjs.com/libraries/mathquill/0.10.1. Note that jQuery is also required.

```js title="script.js"
const mathFieldSpan = document.getElementById("math-field");
const latexSpan = document.getElementById("latex");

const MQ = MathQuill.getInterface(2); // for backcompat
const mathField = MQ.MathField(mathFieldSpan, {
  spaceBehavesLikeTab: true, // configurable
  handlers: {
    edit: function () {
      // useful event handlers
      latexSpan.textContent = mathField.latex(); // simple API
    },
  },
});
```
