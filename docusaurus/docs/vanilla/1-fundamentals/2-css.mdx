# CSS

So far our page is very plain. <abbr title="Cascading Style Sheets">CSS</abbr> allows us to add styling. We will continue trying to reproduce the <a href="/content/vanilla/1-fundamentals/3-js/bases/" target="_blank">number bases</a> example.

Helpful links from MDN:

- [CSS layout](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/CSS_layout)

## Adding a stylesheet

There are a couple of different ways to add styling to a page. The first is with a <MDN tag="style"/> tag.

<LivePreview>
  <MDXPre>
    <MDXCode className="language-html" metastring={`title="index.html"`}>
      {modify(basesHtmlOnly, doc =>
        doc.line("<body>")
        .after(`
          <style>
            body {
              font-family: sans-serif;
            }
          </style>
        `, 2)
      )}
    </MDXCode>
  </MDXPre>
</LivePreview>

However, it is better to split our CSS into a separate file and include it with the <MDN tag="link" /> tag.

<LivePreview>
  <MDXPre>
    <MDXCode className="language-html" metastring={`title="index.html"`}>
      {basesHtmlWithLink}
    </MDXCode>
  </MDXPre>
  ```css title="bases.css"
  body {
    font-family: sans-serif;
  }
  ```
</LivePreview>

## Table styling

### Zebra effect

Subtly alternating the background colors of table rows makes them significantly easier to read. We can achieve this with the <CSSSelector selector=":nth-of-type" /> pseudo-class.

<LivePreview>

  ```css title="bases.css"
  /* reset styles */
  * {
    box-sizing: border-box;
    margin: 0;  
    padding: 0;
  }

  body {
    background: #eee;
    font-family: sans-serif;
  }

  main {
    /* colors and borders */
    background: #fff;
    border: 1px solid #aaa;
    border-width: 0 1px;

    /* this centers it */
    margin: 0 auto;

    /* dimensions */
    max-width: 75%;
    min-height: 100vh;

    padding: 1em 2em;
  }

  /* add margins back to paragraphs */
  p {
    margin: 1em 0;
  }

  /* table styling */
  table {
    /* try commenting this out to see what goes wrong without it */
    border-collapse: collapse;

    tbody > tr:nth-child(even) {
      background-color: #f3f3f3;
    }

    tbody > tr:nth-child(odd) {
      background-color: #e0e0e0;
    }
    
    /* table header cells */
    > thead th {
      background-color: cornflowerblue;
      padding: 4px 8px;
      text-align: right;
    }

    td {
      font-family: monospace;
      padding: 2px 8px;
      text-align: right;
    }
  }
```

  <MDXPre>
    <MDXCode className="language-html" metastring={`title="index.html"`}>
      {basesHtmlWithMain}
    </MDXCode>
  </MDXPre>
</LivePreview>

### Rounded corners

The easiest way to get rounded corners is to set <CSSProp property="border-radius"/> on the `<table>` and then add <CSSProp property="overflow" value="hidden"/> to clip the edges.

<LivePreview>

  ```css title="bases.css"
  /* reset styles */
  * {
    box-sizing: border-box;
    margin: 0;  
    padding: 0;
  }

  body {
    background: #eee;
    font-family: sans-serif;
  }

  main {
    /* colors and borders */
    background: #fff;
    border: 1px solid #aaa;
    border-width: 0 1px;

    /* this centers it */
    margin: 0 auto;

    /* dimensions */
    max-width: 75%;
    min-height: 100vh;

    padding: 1em 2em;
  }

  /* add margins back to paragraphs */
  p {
    margin: 1em 0;
  }

  /* table styling */
  table {
    /* set a border radius + clip the corners of the table */
    border-radius: 4px;
    overflow: hidden;

    border-collapse: collapse;

    tbody > tr:nth-child(even) {
      background-color: #f3f3f3;
    }

    tbody > tr:nth-child(odd) {
      background-color: #e0e0e0;
    }
    
    /* table header cells */
    > thead th {
      background-color: cornflowerblue;
      padding: 4px 8px;
      text-align: right;
    }

    td {
      font-family: monospace;
      padding: 2px 8px;
      text-align: right;
    }
  }
```

    <MDXCode className="language-html" metastring={`title="index.html"`}>
      {basesHtmlWithMain}
    </MDXCode>
  </MDXPre>
</LivePreview>

## Dark mode

Use the [`light-dark`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/color_value/light-dark) function to specify two variants for light vs dark mode.

You must also add <CSSProp property="color-scheme" value="light dark" /> on <CSSSelector selector=":root"/> to opt-in to both light and dark mode. This is a bit weird-looking; if you just added `color-scheme: dark`, that would _force_ everything into dark mode. You would do this if you want your site to have its own color scheme toggler (like there is on this site) instead of going with the user's system preference.

<LivePreview>

  ```css title="bases.css"
  /* reset styles */
  * {
    box-sizing: border-box;
    margin: 0;  
    padding: 0;
  }
  
  /* opt in to light/dark depending on user preference */
  :root {
    color-scheme: light dark;
  }

  body {
    background: light-dark(#eee, #111);
    color: light-dark(black, white);
    font-family: sans-serif;
  }

  main {
    /* colors and borders */
    background: light-dark(#fff, #333);
    border: 1px solid #aaa;
    border-width: 0 1px;

    /* this centers it */
    margin: 0 auto;

    /* dimensions */
    max-width: 75%;
    min-height: 100vh;

    padding: 1em 2em;
  }

  /* add margins back to paragraphs */
  p {
    margin: 1em 0;
  }

  /* table styling */
  table {
    /* set a border radius + clip the corners of the table */
    border-radius: 4px;
    overflow: hidden;

    border-collapse: collapse;

    tbody > tr:nth-child(even) {
      background-color: light-dark(#f3f3f3, #444);
    }

    tbody > tr:nth-child(odd) {
      background-color: light-dark(#e0e0e0, #555);
    }
    
    /* table header cells */
    > thead th {
      background-color: light-dark(cornflowerblue, darkslateblue);
      padding: 4px 8px;
      text-align: right;
    }

    td {
      font-family: monospace;
      padding: 2px 8px;
      text-align: right;
    }
  }
```

  <MDXPre>
    <MDXCode className="language-html" metastring={`title="index.html"`}>
      {basesHtmlWithMain}
    </MDXCode>
  </MDXPre>
</LivePreview>
