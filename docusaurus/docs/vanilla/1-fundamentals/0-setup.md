# Getting started

## Tooling

### Essentials

You should install the following before going any further:

- [Visual Studio Code](https://code.visualstudio.com/download) (VSCode) for editing code. You can also use [Cursor](https://cursor.com) for an AI-enhanced experience—but I recommend learning fundamentals first, then using AI to accelerate what you could have written by hand, vs having it generate things you don't understand.

- [Git](https://git-scm.com/) for source control. Git is a [very powerful system](https://xkcd.com/1597/), but the [cheat sheet](https://git-scm.com/cheat-sheet) is all you really need to know.

- [Node.js](https://nodejs.org/en/download) for installing JavaScript packages. Click on the "Copy to clipboard" button, paste it into your terminal, and run it.

I will do some examples in VSCode in order to show you its features, but I personally use [LazyVim](https://lazyvim-ambitious-devs.phillips.codes) as an editor. Vim allows you to manipulate text much more quickly, but it has a learning curve, so you shouldn't bother with it if you are newer to programming. If you are interested, start with the [Vim for VSCode](https://marketplace.visualstudio.com/items?itemName=vscodevim.vim) extension and add a keyboard shortcut to toggle Vim mode on/off; once you are using Vim mode 100% of the time, you can try to migrate to LazyVim.

### Git extensions

[GitHub Desktop](https://desktop.github.com/download/) is a GUI Git client.

[LazyGit](https://github.com/jesseduffield/lazygit/) is a Terminal GUI for Git.

### Graphics

- [SVGO](https://svgo.dev) for compressing SVG files

- [GIMP](https://www.gimp.org/downloads/): free raster image editor

- [Inkscape](https://inkscape.org/) free SVG editor

- [ImageOptim](https://imageoptim.com/mac) for compressing raster images

- [FFmpeg](https://ffmpeg.org/) for audio/video manipulation (required to render Liqvid projects to static videos)

- [ImageMagick](https://imagemagick.org/script/download.php#gsc.tab=0) for (advanced) image manipulation
